1. 注意使用终端始终为PowerShell 5，其不支持&&连接符，建议使用分号分隔命令
2. 注意写日志（只要涉及代码改动），放在docs/logs目录下，如果没有则创建
3. 注意找错误时仅分析，不要直接修改代码（除非经user确认）
4. 对于日志：完成后，记录本次操作的关键变更和结果
5. 请在每次编码后，使用cargo fmt格式化代码
6. 如果cargo fmt崩溃（sandbox环境常见问题），必须手动对照Rust标准格式逐文件检查：
   - use声明：单词按字母序排列（如 `{Error, HttpRequest, HttpResponse, web}` 而非 `{web, Error, ...}`）
   - 函数签名：能放一行就放一行，参数过多时统一换行
   - 链式调用：过长时在 `.` 前换行（如 `message\n.recipient\n.strip_prefix(...)`）
   - match臂：`Err(_) => match ... {` 不要写成 `Err(_) => { match ... }`
   - 嵌套if：用 `&& let` 合并，不要嵌套
   - 字符串：超过行宽的format!在内部换行，逗号放在行末
