# 2026-04-30 Web UI 重构

**操作**: 基于 Tomato-Novel-Downloader UI 参考，重构 ReChat Web 界面
**分支**: dev (基于 main)

## 设计参考

从 [Tomato-Novel-Downloader](https://gitcode.com/gh_mirrors/to/Tomato-Novel-Downloader) 提取 5 个核心设计模式：

| 模式 | 说明 |
|------|------|
| 零框架 SPA | 纯 Vanilla JS，无 npm 依赖 |
| include_str! | 3 个前端文件编译进 Rust 二进制 |
| Hash 路由 | `window.location.hash` 驱动 4 个 section 切换 |
| CSS Variables | 完整亮色/暗色/Auto 三模式 |
| 侧边栏布局 | 固定 220px + 右侧主内容 max 1100px |

## 变更摘要

### 新增文件 (3)

| 文件 | 行数 | 说明 |
|------|:---:|------|
| `web/templates/index.html` | 104 | SPA 入口 — 侧边栏(仪表盘/消息流/发送/平台) + 4 个 section |
| `web/templates/app.css` | 295 | CSS 主题 — CSS Variables, 暗色模式, 表格/按钮/徽章组件, 响应式 |
| `web/templates/app.js` | 230 | 交互逻辑 — 路由/主题/HTTP/WebSocket/消息渲染 |

### 修改文件 (1)

| 文件 | 变更 |
|------|------|
| `web/mod.rs` | 138 行静态 HTML → 30 行 include_str! 服务 |

### 4 个页面

| 页面 | hash | 功能 |
|------|------|------|
| 仪表盘 | `#dashboard` | 统计卡片(今日消息/活跃平台/客户端数/待发送) + 最近消息表 |
| 消息流 | `#messages` | WebSocket 实时推送 + 平台/内容筛选 + 消息表格 |
| 发送消息 | `#send` | 表单(平台/会话ID/类型/内容) → WebSocket 或 HTTP API |
| 平台状态 | `#platforms` | Adapter 连接状态卡片 |

### UI 特性

- 🎨 番茄红 (#e74c3c) 主色调 + 暗色 sidebar
- 🌙 亮色/暗色/Auto 三模式主题切换 (localStorage 持久化)
- 🔴 WebSocket 实时消息推送 + 断线自动重连
- 📱 768px 响应式断点
